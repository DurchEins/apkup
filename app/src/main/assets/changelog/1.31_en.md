# What's new in v1.31

- 🎨 **New Material 3 Color Palette:** Fresh, harmonic tonal color schemes for light and dark themes with modernized corner shapes.
- 🔄 **New Updates Tab Icon & Badges:** Modern update icon (`Update`) and horizontal version transition badges (*Installed* → *Available*) on update cards.
- 📳 **Haptic Feedback:** Tactile response when switching tabs inside the floating capsule dock.
- 🛡️ **Optimized Capsule Dock:** Expressive floating navigation bar with animated indicator pills and unclipped notification badges.
- 🏷️ **Optimized Source Filter Chips:** 36.dp filter chips in the updates tab for enhanced layout economy and comfortable touch targets.
- ✨ **Smooth Settings Animation:** Seamless `AnimatedContent` transitions when toggling between detail and compact previews.
- 🎯 **Centered Preview Icons:** Perfectly aligned icons in the settings compact preview matching the main updates view.
- 🔒 **Security Policy:** Added official bilingual security policy (SECURITY.md) for coordinated vulnerability disclosures.
- 🌐 **New Languages:** Added support for 7 world languages (ES, FR, PT, IT, RU, ZH, JA) and Android 13+ per-app language settings.
- ℹ️ **Community Notice:** ApkUp now supports multiple new languages. If you notice any translation issues, awkward phrasing, or layout bugs, feedback and pull requests on GitHub are warmly welcomed!
