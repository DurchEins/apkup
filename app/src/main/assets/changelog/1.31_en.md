# What's new in v1.31

- 🔄 **New Updates Tab Icon:** Modern update icon (`Update`) in the floating capsule dock and header.
- 🛡️ **Optimized Capsule Dock:** Vertically centered badge layout beneath unselected tab icons – eliminates edge clipping.
- 🏷️ **Compact Source Filter Chips:** Sleeker 32.dp filter chips in the updates tab for enhanced layout economy and breathing room.
- ✨ **Smooth Settings Animation:** Seamless `AnimatedContent` transitions when toggling between detail and compact previews.
- 🎯 **Centered Preview Icons:** Perfectly aligned icons in the settings compact preview matching the main updates view.
- 🥚 **Interactive Easter Egg:** Secret easter egg hidden under the About card, revealed with a smooth overscroll pull.
- 🌐 **New Languages:** Added support for 7 world languages (ES, FR, PT, IT, RU, ZH, JA) and Android 13+ per-app language settings.
