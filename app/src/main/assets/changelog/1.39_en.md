# What's new in v1.39

## 🛠️ New & fixed in the current patch (v1.39.5)

- 📖 **Clearer, Easy-to-Read Changelog:** Rewrote the update summary in plain, everyday language without technical jargon or distracting formatting characters.
- ⚖️ **Unified Open-Source License:** Updated all license notices across the app to GPL-3.0 in line with the original base project.
- 📏 **Version Numbers Always Fit:** Long version numbers now automatically adjust their text size so they always fit on a single line without being cut off.
- 🔄 **Live Feedback on "Check for updates":** Tapping "Check for updates" in the About tab now spins the arrow icon while searching and briefly shows a green checkmark right inside the button when you are up to date.
- 💬 **Floating Status Hints:** Short status messages now float cleanly as a rounded capsule above the bottom navigation bar instead of covering it.
- ⚡ **Under-the-Hood Speed & Reliability:** Updated core app components and improved download notifications on Android 16 so progress updates always stay visible.

## ✨ Main Features in v1.39

- 💾 **Downloads Kept for 24 Hours:** Downloaded updates stay saved in the app for a full day. If you accidentally cancel an installation prompt, tapping "Install" immediately starts it again without re-downloading.
- 📦 **More Reliable APKMirror Installations:** The app now accurately distinguishes between regular single-file downloads and bundled app packages so installations finish smoothly.
- 🛠️ **One-Tap Help for Source Errors:** Whenever an update source runs into an issue, the help button takes you straight to the matching step-by-step fix in the troubleshooting guide.
- 🔑 **Instant Token Check for GitHub & GitLab:** You can now test your personal access tokens right inside the input dialog to make sure they work before saving.
- ✨ **Cleaner Settings with Subtle Expand Animation:** Advanced settings are now neatly tucked away by default and open with a gentle animation whenever you need them.
