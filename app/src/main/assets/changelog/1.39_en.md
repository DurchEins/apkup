# What's new

## October

### October 29, 2026 | 1.39.5-Beta (150) | Patch & Fix

- **Redesigned Monthly Changelog** Rebuilt the update overview with collapsible monthly sections, version badges, and plain, easy-to-read language.
- **English Troubleshooting Wiki** One-tap help buttons on source errors now link directly to the English step-by-step troubleshooting guides.
- **Unified Open-Source License** Updated all in-app license notices to GPL-3.0 in line with the original base project.
- **General Improvements** Bug fixes and performance improvements.

### October 26, 2026 | 1.39.0-Beta (148) | Feature Update

> [Banner] 24h Download Cache | + Instant Reinstall

- **Downloads Kept for 24 Hours** Downloaded updates stay saved in the app for a full day. If you cancel an installation prompt, tapping "Install" immediately starts it again without re-downloading.
- **Live Feedback on "Check for updates"** Tapping "Check for updates" in the About tab spins the arrow icon while searching and briefly shows a green checkmark right inside the button when you are up to date.
- **Version Numbers Always Fit** Long version numbers now automatically adjust their text size so they always fit on a single line without being cut off.
- **Floating Status Hints** Short status messages now float cleanly as a rounded capsule above the bottom navigation bar instead of covering it.
- **General Improvements** More reliable download notifications on Android 16 and updated core app components for better stability.

### October 19, 2026 | 1.32.0-Beta (138) | Feature Update

- **Direct APKMirror Downloads** Bundled app packages and single-file updates from APKMirror are now downloaded and unpacked directly inside the app.
- **Active Download Queue** Track and cancel individual running downloads at any time via the live download queue sheet.
- **Instant Token Check for GitHub & GitLab** Test your personal access tokens right inside the input dialog to verify they work before saving.
- **General Improvements** Added Wi-Fi-only data saver mode and improved background update check progress notifications.
