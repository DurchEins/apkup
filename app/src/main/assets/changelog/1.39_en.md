# What's new in v1.39

## 🛠️ New & fixed in the current patch (v1.39.4)

- ⚖️ **License Alignment to GNU GPL v3.0 (`GPL-3.0`):** Aligned ApkUp's project license with the upstream *APKUpdater* project (`rumboalla/apkupdater`) under the **GNU General Public License v3.0 (GPL-3.0)** across `LICENSE`, `README.md`, and the *About* section in all 9 languages.
- 📏 **Dynamic Version Font Scaling (`AutoResizeText`):** Long or multi-digit version strings (including 3–4 digit segments) in Settings and the Changelog header now automatically scale down to fit on a single line without ellipsis truncation (`...`).
- ⚡ **Updated Core Libraries & Engine Optimizations:** Upgraded core AndroidX, networking, and UI dependencies (`OkHttp 5.5.1`, `Coil 3.6.3`, `Koin 4.2.2`, `Lifecycle 2.11.0`, `Navigation 2.10.2`, `WorkManager 2.12.0`, `Coroutines 1.11.0`) alongside expanded KDoc architecture documentation.
- 🔄 **Live Feedback on "Check for updates":** Tapping "Check for updates" in the *About* tab now spins the refresh arrow icon smoothly while checking and morphs into a green checkmark (*"Up to date ✓"*) for 2.5 seconds — with no intrusive pop-up.
- 💬 **Floating Material-You Capsule Pop-ups:** All app snackbars now float cleanly above the bottom navigation dock as a rounded Material-You card with a leading status icon.
- 🔔 **Android 16 Notification Throttling Fix:** Eliminated duplicate progress triggers on download start so Android 16 never sheds foreground notifications due to rate limits.

## ✨ Main Features in v1.39

- 💾 **Persistent 24h Download Storage & Instant Re-Install:** Downloaded APKs remain cached in dedicated app storage (`filesDir/downloads`). After cancelling the Android package installer prompt, tapping "Install" (across both primary and alternative update sources) immediately re-launches the installer without re-downloading.
- 📦 **Reliable APKMirror Single-APK & `.apkm` Detection:** Direct APKMirror downloads now always inspect the actual archive root (`AndroidManifest.xml`) before extraction, preventing standalone `.apk` files from being misclassified as `.apkm` split bundles.
- 🛠️ **Wiki Self-Help Catalog & Error Deep-Linking:** Tapping "Wiki help ↗" on source error banners now jumps directly to the matching troubleshooting section in the expanded GitHub Wiki (DNS, timeouts, rate limits, HTTP 404/5xx, Cloudflare, signature conflicts).
- 🔑 **Live Token Verification for GitHub & GitLab:** Personal Access Tokens can now be verified live inside the dialog ("Verify token") and automatically upon saving, displaying your username and remaining API rate limit.
- ✨ **Collapsible Advanced Settings & Compact Bento Layout:** "Advanced Settings" are now collapsed by default (featuring a subtle open-only gear spin & light shimmer effect plus a compact install-permission status bar), and the "Check for updates" / "What's new" Bento tiles are now much sleeker.
