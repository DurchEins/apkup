# v1.37 更新内容

- ⚡ **24小时安装缓存：** 已下载的 APK 会在暂存区保留长达 24 小时。即使系统安装弹窗被关闭，也可随时点击“安装”立即继续，无需重新下载。
- 📥 **应用内直连下载 APKMirror：** APKMirror 更新现已支持在应用内直接下载并安装，无需跳转浏览器手动操作。
- 📦 **Split-APK 分包 (.apkm) 支持：** 自动解压并通过 Android Session API 无缝安装 `.apkm` 分包。
- 📋 **Play 商店风格的活动队列：** 全新交互式实时横幅与底部面板，支持查看单应用进度、单独/全部取消以及已完成列表。
- 🔔 **检查更新与下载实时通知：** 后台检查更新时提供状态栏静默进度通知，以及交互式前台下载通知。
- 📶 **省流模式（仅限 Wi-Fi 下载）：** 可限制仅在 Wi-Fi 下下载更新，连接移动数据时会弹出二次确认。
- 🔑 **GitLab API 令牌与密码遮罩：** 支持 GitLab 个人访问令牌 (`read_api`)，并为 GitHub 和 GitLab 令牌输入框添加了眼睛显隐按钮。
- 🛡️ **智能 Cloudflare 回退与稳定性提升：** 遇到 APKMirror 人机验证时自动唤起浏览器，提供超时自动重试，以及 Google Play 频率限制保护。
