# v1.31 の新機能

- 🎨 **新しい Material 3 カラーパレット:** ライトおよびダークテーマ向けの調和の取れたトーン配色と現代的な角丸形状。
- 🔄 **新しい更新タブアイコンとバッジ:** 新しい更新アイコン（`Update`）と、更新カード上の水平バージョン表示（*インストール済み* → *利用可能*）。
- 📳 **触覚フィードバック:** フローティングカプセルドックでタブを切り替える際の心地よい触覚フィードバック。
- 🛡️ **最適化されたカプセルドック:** アニメーション付きインジケーターピルと端の切り欠きを防ぐ安全な通知バッジ配置。
- 🏷️ **最適化されたソースフィルターチップ:** 更新タブの36.dpチップによる快適なタッチ操作と見やすさの向上。
- ✨ **滑らかな設定アニメーション:** 詳細プレビューとコンパクトプレビューの切り替え時における継ぎ目のない `AnimatedContent` 遷移。
- 🎯 **中央揃えのプレビューアイコン:** 設定のコンパクトプレビューにおいてメインビューと同様に正確に揃えられたアイコン。
- 🔒 **セキュリティポリシー:** 責任ある脆弱性報告のための公式2言語セキュリティポリシー（SECURITY.md）を追加。
- 🌐 **新しい言語の追加:** 7つの世界言語（ES、FR、PT、IT、RU、ZH、JA）および Android 13+ のアプリ別言語設定に対応。
- ℹ️ **コミュニティへのお願い:** ApkUp は多くの新しい言語に対応しました。誤訳やレイアウトの不具合にお気づきの際は、GitHub でのフィードバックやプルリクエストを心よりお待ちしております！
