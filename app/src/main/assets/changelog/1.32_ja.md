# v1.32 の新機能

- 📥 **APKMirror のアプリ内直接ダウンロード:** ブラウザを開かずに、APKMirror の更新をアプリ内で直接ダウンロード・インストールできるようになりました。
- 📦 **Split-APK バンドル (.apkm) 対応:** `.apkm` パッケージの自動展開と Android セッション API によるシームレスなインストールに対応しました。
- 📋 **Play ストア風のアクティブキュー:** アプリごとの進捗表示、個別・一括キャンセル、完了済みリストを確認できるライブバナーとボトムシートを追加しました。
- 🔔 **検索とダウンロードのライブ通知:** バックグラウンドでの更新チェック中の進捗通知と、インタラクティブなダウンロード通知に対応しました。
- 📶 **Wi-Fi のみでダウンロード（データセーバー）:** モバイルデータ通信時の誤ダウンロードを防ぐ確認ダイアログ付きオプションを追加しました。
- 🔑 **GitLab API トークンとマスク表示:** GitLab トークン (`read_api`) のサポートと、GitHub / GitLab トークンのパスワードマスク表示を追加しました。
- 🛡️ **Cloudflare フォールバックと安定性向上:** APKMirror の認証制限時のブラウザ自動切り替え、タイムアウト再試行、Google Play のレート制限対策を強化しました。
