# Novedades en v1.32

- 📥 **Descargas directas de APKMirror:** Las actualizaciones de APKMirror ahora se descargan e instalan directamente en la app sin abrir el navegador.
- 📦 **Soporte para paquetes Split-APK (.apkm):** Extracción e instalación automática de paquetes `.apkm` mediante la API de sesiones de Android.
- 📋 **Cola activa estilo Play Store:** Nuevo banner interactivo y panel inferior con progreso por aplicación, cancelación individual o total y lista de completados.
- 🔔 **Notificaciones en vivo de búsqueda y descarga:** Progreso silencioso en la barra de estado al buscar actualizaciones en segundo plano y notificaciones interactivas de descarga.
- 📶 **Ahorro de datos (Solo por Wi-Fi):** Opción para limitar las descargas a redes Wi-Fi con confirmación al usar datos móviles.
- 🔑 **Token de API de GitLab y ocultación:** Soporte para tokens de GitLab (`read_api`) y visualización protegida para tokens de GitHub y GitLab.
- 🛡️ **Resiliencia y alternativa Cloudflare:** Cambio automático al navegador ante desafíos de Cloudflare, reintentos automáticos y protección en Google Play.
