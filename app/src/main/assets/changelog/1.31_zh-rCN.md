# v1.31 更新说明

- 🔄 **全新“更新”标签图标：** 浮动胶囊底栏与顶部标题栏均已采用现代化的 `Update` 刷新图标。
- 🛡️ **优化胶囊导航底栏：** 未选中的标签图标下方采用垂直居中的小红点角标，彻底解决边缘裁剪问题。
- 🏷️ **更紧凑的更新源筛选标签：** 更新标签页采用 32.dp 紧凑筛选标签，节省垂直空间，浏览更加清爽。
- ✨ **丝滑的设置预览动画：** 在详细模式与紧凑模式切换时呈现自然的 `AnimatedContent` 动效。
- 🎯 **居中对齐的预览图标：** 设置页面中的紧凑预览卡片图标与主界面完全保持居中一致。
- 🌐 **多语言本地化：** 新增 7 种全球主流语言支持（ES、FR、PT、IT、RU、ZH、JA）及 Android 13+ 应用级语言选择。
- ℹ️ **社区提示：** ApkUp 现已支持多种新语言。如果您发现任何表述不当或排版问题，非常欢迎在 GitHub 上提交反馈或发起 Pull Request！
