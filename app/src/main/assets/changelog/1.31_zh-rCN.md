# v1.31 更新日志

- 🎨 **全新 Material 3 调色板:** 浅色与深色主题下的全新和谐色调方案，搭配现代化的圆角设计。
- 🔄 **全新“更新”标签图标与徽标:** 全新的刷新图标（`Update`）及更新卡片上的水平版本转换标签（*已安装* → *可用新版*）。
- 📳 **触觉震动反馈:** 在悬浮胶囊底栏切换标签时提供细腻利落的触觉反馈。
- 🛡️ **优化胶囊底栏:** 带有平滑动画指示胶囊的悬浮导航栏，彻底消除角标被边框裁切的问题。
- 🏷️ **优化来源过滤标签:** 更新标签页采用 36.dp 过滤芯片，带来更舒适的触控操作与视觉空间。
- ✨ **流畅的设置界面动画:** 在详细预览与紧凑预览之间切换时享受平滑的 `AnimatedContent` 动画过渡。
- 🎯 **居中对齐预览图标:** 设置中的紧凑预览图标与主界面保持完全一致的居中对称。
- 🔒 **安全政策:** 新增官方双语安全政策（SECURITY.md），以便规范报告安全隐患。
- 🌐 **新增多语言支持:** 新增支持 7 种全球语言（ES、FR、PT、IT、RU、ZH、JA）及 Android 13+ 单应用语言偏好设置。
- ℹ️ **社区反馈:** ApkUp 现已支持多种全新语言。如果您发现任何翻译纰漏或排版异常，热烈欢迎前往 GitHub 提交 Issue 或 Pull Request！
