# What's new in v1.27

- 🛠️ **Google Play Store Installation Fix:** Resolved an issue where app installations from Google Play Store without Shizuku silently stopped. Staged APK files now strictly end with `.apk`, Android 14–17 Background Activity Launch restrictions are handled correctly, and GZIP-compressed CDN streams are automatically decompressed.
- 📋 **In-App Changelog:** New Material 3 "What's new" dialog presenting release highlights automatically after updates and accessible anytime via Settings.
- 🎨 **Material 3 Expressive UI:** Refined UI components, optimized bottom sheet layouts, and smoother navigation across the app.
- ⚡ **Stability & Performance:** Hardened R8/ProGuard rules against bytecode stripping and clean background execution for downloads and update checks.
