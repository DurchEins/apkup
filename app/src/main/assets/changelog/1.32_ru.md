# Что нового в v1.32

- 📥 **Прямая загрузка с APKMirror:** Обновления из APKMirror теперь скачиваются и устанавливаются прямо в приложении без перехода в браузер.
- 📦 **Поддержка Split-APK (.apkm):** Автоматическая распаковка и установка пакетов `.apkm` через сессионный API Android.
- 📋 **Активная очередь в стиле Play Store:** Интерактивный баннер и панель со статусом каждого приложения, отменой и списком завершённых обновлений.
- 🔔 **Живые уведомления о поиске и загрузке:** Тихое уведомление с прогрессом при проверке обновлений в фоне и интерактивные уведомления загрузки.
- 📶 **Экономия трафика (Только по Wi-Fi):** Опция загрузки обновлений только по Wi-Fi с подтверждением при использовании мобильных данных.
- 🔑 **API-токен GitLab и маскировка:** Поддержка токенов GitLab (`read_api`) и скрытие символов токенов GitHub и GitLab.
- 🛡️ **Защита от сбоев и Cloudflare:** Автоматический переход в браузер при проверках Cloudflare, повтор при тайм-аутах и защита от лимитов Google Play.
