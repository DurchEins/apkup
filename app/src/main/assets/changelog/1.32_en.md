# What's new in v1.32

- 📥 **Direct In-App APKMirror Downloads:** APKMirror updates can now be downloaded and installed directly within the app without manual browser redirection.
- 📦 **Split-APK Bundle (.apkm) Support:** Seamless automatic extraction and installation of multi-APK `.apkm` packages via Android's PackageInstaller session API.
- 🛡️ **Intelligent Cloudflare Fallback:** Gracefully falls back to browser navigation when encountering bot verification challenges or rate limits.
- ⚙️ **Source Preferences:** Granular toggle in Settings to control direct APKMirror downloads at any time.
- 🚀 **Foreground Download Service:** Download jobs and bulk updates now persist reliably in the background across screen-locks and app minimization.
- 🔔 **Interactive Progress Notification:** Real-time ongoing system notification displaying current app title, animated progress bar, and instant cancellation.
- 🔄 **Google Play Store Resiliency:** Concurrency protection with mutex locking and automatic anonymous account rotation on HTTP 429 throttling.
