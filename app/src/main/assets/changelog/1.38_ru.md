# Что нового в v1.38

- ⚡ **Плавное возобновление без перезапуска приложения:** Отмена диалога установки системы больше не блокирует приложение. Установку кэшированных APK можно возобновить мгновенно нажатием «Установить».
- 🔄 **Надежное управление сессиями PackageInstaller:** Сессии установки Android корректно освобождаются и закрываются при отмене или повторе.
- 📦 **24-часовой кэш установки:** Загруженные APK хранятся до 24 часов, предотвращая повторные загрузки.
- 📋 **Очередь и уведомления в реальном времени:** Отслеживание статуса всех загрузок и фоновых проверок обновлений.
- 🌐 **Полная локализация:** Качественные переводы для всех 23 поддерживаемых языков в чистой кодировке UTF-8.
