# What's new in v1.38

- ⚡ **Seamless Resume Without App Restart:** Canceling the system package installer prompt no longer blocks the app. Cached APK installations can now be resumed immediately with 'Install'.
- 🔄 **Reliable PackageInstaller Session Handling:** System install sessions are now cleanly released and abandoned whenever cancelled or retried.
- 📦 **24-Hour Installation Cache:** Downloaded APKs are preserved for up to 24 hours so you never have to re-download after dismissing an install dialog.
- 📋 **Live Queue & Notifications:** Real-time visibility into all downloads and background update checks.
- 🌐 **Full Localization:** Clean translations across all 23 supported languages with pristine UTF-8 encoding.
