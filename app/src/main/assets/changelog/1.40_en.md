# What's new

## November

### November 5, 2026 | 1.40.1-Beta (153) | Patch & Fix

- **Enhanced Obtainium Compatibility** Harmonized recognition and linking of multi-level GitLab project paths.
- **General Improvements** Internal code cleanup and hardening to enhance overall stability and remove unused configurations.

### November 5, 2026 | 1.40.0-Beta (152) | Feature Update

> [Banner] F-Droid Index V2 | + Obtainium Sync

- **F-Droid Index V2 Support** The IzzyOnDroid repository now uses the modern F-Droid Index V2 specification. Using lightweight index checks and smart caching, update scans are now virtually instantaneous with minimal data usage.
- **Obtainium Backup Import & Export** ApkUp can now directly import app repository configurations from Obtainium and export your custom bindings back to Obtainium.
- **General Improvements** Enhanced self-hosted GitLab URL parsing and refined background download reliability.

- **Redesigned Monthly Changelog** Grouped the update history by actual release months with color-coded version badges and visual highlight banners for every feature release.

- **General Improvements** Bug fixes and visual refinements.
