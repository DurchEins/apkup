# What's new in v1.36

- ⚡ **24-Hour Installation Cache:** Downloaded APKs are preserved in staging for up to 24 hours. If an installation dialog is dismissed, it can be resumed instantly without re-downloading.
- 📥 **Direct In-App APKMirror Downloads:** APKMirror updates now download and install directly within the app without manual browser redirection.
- 📦 **Split-APK Bundle (.apkm) Support:** Seamless automatic extraction and installation of multi-APK `.apkm` packages via Android's PackageInstaller session API.
- 📋 **Play Store-Style Active Queue:** New interactive live banner and bottom sheet showing per-app progress, individual or batch cancellation, and completed updates.
- 🔔 **Live Search & Download Notifications:** Silent ongoing status bar progress when leaving the app during an update scan, plus interactive foreground download notifications.
- 📶 **Wi-Fi Only Data Saver:** Optional setting to restrict update downloads to Wi-Fi with a confirmation dialog when on mobile data.
- 🔑 **GitLab API Token & Token Masking:** Support for GitLab Personal Access Tokens (`read_api`) and masked token input with visibility toggle for both GitHub and GitLab.
- 🛡️ **Smart Cloudflare Fallback & Resiliency:** Automatic browser fallback on APKMirror challenges, timeout retries, and Google Play Store rate-limit protection.
