# What's new in v1.30

- 📦 **IzzyOnDroid Update Source:** Direct integration of the curated IzzyOnDroid repository featuring mandatory SHA-256 certificate matching and native ABI/SDK compatibility filtering.
- 🚀 **Integrated ApkUp Self-Updater:** Automatic detection of new GitHub releases and smooth in-app self-updating without relying on external app stores.
- ⚡ **Parallel Download Engine:** Fast simultaneous downloads for up to 3 updates paired with an orderly, sequential installation queue for maximum stability.
- 📋 **Dynamic In-App Changelog:** Enhanced distinction between clean installs and upgrades along with dynamic version-matching changelog loading.
