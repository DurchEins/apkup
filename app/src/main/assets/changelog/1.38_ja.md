# v1.38 の新機能

- ⚡ **アプリ再起動不要のスムーズな再開:** システムのインストール画面をキャンセルしてもアプリがフリーズしなくなりました。キャッシュされたAPKは「インストール」ですぐに再開できます。
- 🔄 **確実な PackageInstaller セッション管理:** キャンセルや再試行時にシステムセッションを適切に解放・破棄します。
- 📦 **24時間インストールキャッシュ:** ダウンロードしたAPKを最大24時間保持し、再ダウンロードを防ぎます。
- 📋 **リアルタイムキューと通知:** ダウンロードやバックグラウンド更新確認の進捗をリアルタイムに確認可能。
- 🌐 **完全な多言語対応:** サポートされている23言語すべてで正確な翻訳とクリーンなUTF-8エンコードを提供します。
