# v1.32 更新内容

- 📥 **APKMirror 应用内直接下载：** 现在可直接在应用内下载并安装 APKMirror 更新，无需跳转浏览器。
- 📦 **支持 Split-APK (.apkm) 捆绑包：** 通过 Android PackageInstaller 会话 API 自动解压并安装 `.apkm` 软件包。
- 📋 **Play 商店风格的活动队列：** 全新交互式横幅与底部面板，支持查看单应用进度、单独或全部取消以及已完成列表。
- 🔔 **后台检查与下载实时通知：** 检查更新期间切换至后台时静默显示状态栏进度，并提供交互式下载进度通知。
- 📶 **省流模式（仅在 Wi-Fi 下下载）：** 可选仅通过 Wi-Fi 下载更新，使用移动数据时弹窗确认。
- 🔑 **GitLab API 令牌与密码掩码：** 新增 GitLab 个人访问令牌 (`read_api`) 支持，并为 GitHub 与 GitLab 令牌提供隐藏/显示切换。
- 🛡️ **智能 Cloudflare 回退与稳定性提升：** 遇到验证挑战时自动回退至浏览器，增强超时重试与 Google Play 限流保护。
