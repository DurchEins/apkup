# ApkUp v1.31-Beta Release Notes

## Highlights & Improvements

- 🔄 **New Updates Tab Icon:** Modernized the Updates tab with a streamlined `Update` icon in both the floating capsule dock and header.
- 🛡️ **Centered Capsule Dock Badges:** Redesigned unselected tab items into vertically aligned columns with badges centered directly beneath icons, eliminating edge clipping.
- 🏷️ **Compact Source Filter Chips:** Compact 32.dp filter chips in the Updates view provide more vertical space and cleaner layout hierarchy.
- ✨ **Smooth AnimatedContent Transitions:** Seamless fade and scale transitions when switching between Detail and Compact update views in Settings.
- 🎯 **Centered Settings Preview:** Perfectly aligned icon containers in the Settings compact preview matching the main screen layout.
- 🥚 **Interactive Pull-to-Reveal Easter Egg:** Secret easter egg cleanly hidden beneath the About card, revealed with a tactile overscroll pull gesture and elastic spring-back.
- 🌐 **Expanded Localization (i18n):** Added comprehensive translations for 7 major world languages (Spanish, French, Portuguese, Italian, Russian, Simplified Chinese, Japanese) with Android 13+ per-app language support.
