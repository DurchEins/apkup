Suma SHA-256 en vivo

Una suma SHA-256 es la huella digital única de 64 caracteres del APK. Si cambia aunque sea un solo byte, el hash no coincidirá.

Comandos de verificación local

Ejecuta el comando de tu sistema en la carpeta de Descargas para calcular el hash SHA-256 de tu archivo y compararlo con el oficial de la izquierda.

Guía paso a paso en la Wiki →
Linux / macOS sha256sum -c SHA256SUMS
Windows PowerShell Get-FileHash .\ApkUp-*.apk -Algorithm SHA256
