Android 10 – 17 • Guía de Sideloading

Instalar aplicaciones desconocidas en Android

Cómo activar el permiso «Instalar apps desconocidas» de Android en 30 segundos — o usar Shizuku, ADB o Root para actualizaciones silenciosas.

Android estándar • 30 segundos

Permiso clásico «Instalar apps desconocidas»

  1. 01
    Descarga y abre la última APK firmada

    Descarga el último archivo .apk(Up) firmado desde nuestra página de Descargas o GitHub Releases y tócalo en tu navegador o gestor de archivos.

  2. 02
    Activa «Permitir desde esta fuente»

    Cuando Android lo solicite, toca Ajustes, activa Permitir desde esta fuente para tu navegador y toca Instalar.

  3. 03
    Concede el permiso una vez a ApkUp

    En tu primera actualización dentro de ApkUp, concede el mismo permiso a ApkUp una sola vez — o usa Shizuku/Root para actualizaciones silenciosas.

Shizuku • ADB • Root

Vía avanzada con Shizuku o ADB

Instalar mediante Shizuku (Depuración inalámbrica en Android 11+), adb install -r ApkUp.apk desde un PC o Root (su) utiliza directamente la canalización de desarrollador del sistema.
