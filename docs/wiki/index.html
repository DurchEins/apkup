Setting up Shizuku & Optional Root (su) Shizuku & optionales Root (su) einrichten

Standard Android installs work immediately without Shizuku or Root. Enable Shizuku if you want unattended background installs without repetitive system prompts. Die normale Installation funktioniert jederzeit ohne Shizuku oder Root. Mit Shizuku oder Root laufen geprüfte Updates auf Wunsch lautlos im Hintergrund.

  1. Install Shizuku and start it via Wireless Debugging (Android 11+) or ADB. Installiere Shizuku und starte den Dienst per Wireless Debugging (ab Android 11) oder ADB.
  2. Open ApkUp → Setup → Background Installation and grant Shizuku permission (or enable Root su). Öffne in ApkUp Setup → Hintergrund-Installation und erteile Shizuku die Freigabe (oder aktiviere Root su).
  3. Optionally enable Wi-Fi only, While charging, and active time windows. Lege optional Regeln für Nur über WLAN, Nur beim Laden sowie Ruhezeiten fest.

F-Droid & Index V2 Repositories

ApkUp supports official F-Droid, IzzyOnDroid, and custom HTTPS repositories with cryptographic JAR certificate verification and incremental Index V2 diffs. ApkUp unterstützt das offizielle F-Droid, IzzyOnDroid sowie eigene HTTPS-Repositories inklusive kryptografischer JAR-Prüfung und sparsamen Index-V2-Diffs.

  • Add custom repos under Setup → Update Sources → IzzyOnDroid / F-Droid using presets or a ?fingerprint= URL. Eigene Repos fügst du unter Setup → Update-Quellen → IzzyOnDroid / F-Droid per Preset oder ?fingerprint=-URL hinzu.
  • Your installed app list is never sent to F-Droid or IzzyOnDroid — comparisons run strictly on-device. Deine App-Liste wird niemals an F-Droid oder IzzyOnDroid gesendet – der Abgleich erfolgt rein lokal.

GitHub, GitLab & Codeberg Tokens Zugangs-Tokens für GitHub, GitLab & Codeberg

Public repositories work without a token. Adding a GitHub Personal Access Token raises rate limits and unlocks batched GraphQL update checks. All tokens are encrypted via Google Tink and strictly host-isolated across redirects. Öffentliche Repositories funktionieren ohne Token. Ein GitHub-Token erhöht das Abfragelimit und aktiviert gebündelte GraphQL-Checks. Alle Tokens werden per Google Tink verschlüsselt und niemals über Redirects an fremde Hosts gesendet.

Obtainium Migration & Sync

Import your Obtainium JSON backup in Setup → Backup & Import to preview matched apps, multi-level GitLab subgroups, custom F-Droid repos, and watchlist entries before applying. Importiere dein Obtainium-JSON-Backup unter Setup → Sicherung & Import, prüfe erkannte Apps, GitLab-Subgroups, eigene F-Droid-Repos und Merklisten-Einträge in der Vorschau und übernehme sie mit einem Tipp.

Troubleshooting Source Errors Fehlerbehebung bei Quellen

  • HTTP 403 / 429 on GitHub: Add a read-only Personal Access Token in Setup. HTTP 403 / 429 bei GitHub: Hinterlege im Setup ein Read-Only Personal Access Token.
  • APKMirror Cloudflare challenge: ApkUp automatically opens an in-app WebView or browser fallback. APKMirror-Cloudflare-Prüfung: ApkUp öffnet automatisch eine In-App-WebView oder den Browser-Fallback.
  • Signature mismatch warning: The downloaded APK uses a different signing key than the installed app and is blocked for your safety. Signatur-Warnung: Die neue APK nutzt einen anderen Signaturschlüssel als die installierte App und wird zu deinem Schutz blockiert.
