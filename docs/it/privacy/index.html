Informativa sulla privacy

Ultimo aggiornamento: 13 novembre 2026 • Basata su PRIVACY.md nel repository ApkUp.

✓ 100% sul dispositivo
  • Scansione app, confronto versioni e verifica SHA-256
  • Token cifrati via hardware con Google Tink (AES-256-GCM)
✕ Mai inviato
  • Zero telemetria, tracker di crash o ID pubblicitari
  • Nessun server sviluppatore, account utente o statistiche

1. Nessun server sviluppatore, statistiche o pubblicità

  • Nessun server ApkUp, proxy o database che registri richieste o indirizzi IP.
  • Nessuna registrazione, account utente, tracker (Firebase, Sentry, Crashlytics) o telemetria.
  • Non raccoglie mai IMEI, numeri di serie, indirizzi MAC o ID pubblicitari.

2. Consenso esplicito alle sorgenti e attività di rete

  • Al primo avvio ApkUp mostra una finestra per scegliere le sorgenti — prima non avviene alcuna richiesta esterna.
  • Gli indici F-Droid e IzzyOnDroid vengono scaricati e confrontati localmente senza inviare la lista app.
  • I controlli Google Play usano token anonimi Aurora Dispenser con profilo minimo — nessun account personale.

3. Archiviazione locale cifrata e codice aperto

Tutte le preferenze, collegamenti e token opzionali sono cifrati a riposo via Google Tink (AES-256-GCM) su Android Keystore. Backup cloud e HTTP in chiaro sono disabilitati.
