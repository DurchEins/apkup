Живая сумма SHA-256

Контрольная сумма SHA-256 — это уникальный 64-символьный цифровой отпечаток APK. Если изменён хотя бы один байт, хэш не совпадёт.

Команды локальной проверки

Выполните команду для вашей ОС в папке Загрузки, чтобы вычислить SHA-256 вашего файла и сравнить с официальной суммой слева.

Пошагово в Вики →
Linux / macOS sha256sum -c SHA256SUMS
Windows PowerShell Get-FileHash .\ApkUp-*.apk -Algorithm SHA256
