Android 10 – 17 • Sideloading Guide

Installing Unknown Apps on Android

How to enable Android’s “Install unknown apps” permission in 30 seconds — or use Shizuku, ADB, or Root for silent background updates.

Standard Android • 30 Seconds

Classic “Install Unknown Apps” Permission

  1. 01
    Download & open the latest signed APK

    Download the latest signed .apk(Up) file via our Downloads page or GitHub Releases and tap the file in your browser or file manager.

  2. 02
    Enable “Allow from this source”

    When Android prompts you, tap Settings, switch on Allow from this source for your browser, and tap Install.

  3. 03
    Grant permission once to ApkUp

    On your first app update inside ApkUp, grant the same permission to ApkUp once — or use Shizuku/Root for completely silent background updates.

Shizuku • ADB • Root

Power-User Path via Shizuku or ADB

Installing via Shizuku (Wireless Debugging on Android 11+), adb install -r ApkUp.apk from a PC, or Root (su) uses Android’s developer package installer pipeline directly.
