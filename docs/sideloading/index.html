Android 10 – 17 • Sideloading Guide

Installing Unknown Apps on Android Unbekannte Apps auf Android installieren

How to enable Android’s “Install unknown apps” permission in 30 seconds — or use Shizuku, ADB, or Root for silent background updates. So aktivierst du die Berechtigung „Unbekannte Apps installieren“ in 30 Sekunden – oder nutzt optional Shizuku, ADB bzw. Root für lautlose Hintergrund-Updates.

Standard Android • 30 Seconds Standard-Android • 30 Sek.

Classic “Install Unknown Apps” Permission Klassische Berechtigung „Unbekannte Apps installieren“

  1. 01
    Download & open the latest signed APK Neueste signierte APK herunterladen & antippen

    Download the latest signed .apk(Up) file via our Downloads page or GitHub Releases and tap the file in your browser or file manager. Lade die neueste signierte .apk(Up)-Datei über unsere Downloads-Seite oder GitHub Releases herunter und tippe die Datei im Browser oder Dateimanager an.

  2. 02
    Enable “Allow from this source” „Aus dieser Quelle zulassen“ aktivieren

    When Android prompts you, tap Settings, switch on Allow from this source for your browser, and tap Install. Tippe im Android-Hinweis auf Einstellungen, aktiviere Aus dieser Quelle zulassen für deinen Browser und tippe auf Installieren.

  3. 03
    Grant permission once to ApkUp Berechtigung einmalig auch für ApkUp freigeben

    On your first app update inside ApkUp, grant the same permission to ApkUp once — or use Shizuku/Root for completely silent background updates. Beim ersten App-Update in ApkUp gibst du dieselbe Berechtigung einmalig für ApkUp frei – oder nutzt optional Shizuku/Root für lautlose Hintergrund-Updates.

Shizuku • ADB • Root

Power-User Path via Shizuku or ADB Power-User-Weg über Shizuku oder ADB

Installing via Shizuku (Wireless Debugging on Android 11+), adb install -r ApkUp.apk from a PC, or Root (su) uses Android’s developer package installer pipeline directly. Installationen über Shizuku (Kabelloses Debugging ab Android 11), adb install -r ApkUp.apk vom PC oder Root (su) nutzen direkt die Entwickler-Schnittstelle des Android-PackageInstallers.
