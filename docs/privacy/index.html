Privacy Policy

Last Updated: November 24, 2026 • Based on PRIVACY.md in the ApkUp repository.

✓ 100% On-Device
  • App scan, version matching & SHA-256 verification
  • Hardware-backed Google Tink (AES-256-GCM) tokens
✕ Never Sent
  • Zero telemetry, crash trackers, or advertising IDs
  • No developer backend, user accounts, or analytics

1. No Developer Backend, Analytics, or Ads

  • No ApkUp servers, proxy servers, or databases logging user queries or IP addresses.
  • No registration, user accounts, crash trackers (Firebase, Sentry, Crashlytics), or behavioral telemetry.
  • Never collects IMEI, hardware serials, MAC addresses, or Advertising IDs.

2. Explicit Source Consent & Network Activity

  • On first launch, ApkUp presents a Choose Update Sources consent dialog — zero external requests happen beforehand.
  • F-Droid & IzzyOnDroid indexes are downloaded and compared locally on your device without transmitting your app list.
  • Google Play checks generate anonymous sessions directly on-device without a third-party dispenser server, using a minimized compatibility profile — no personal Google account is used.

3. Encrypted Local Storage & Auditing

All preferences, bindings, and optional API tokens are encrypted at rest via Google Tink (AES-256-GCM) backed by Android Keystore. Cloud backups and cleartext HTTP are disabled.

4. Companion Website (durcheins.github.io/apkup)

  • Hosted statically on GitHub Pages (github.io) with zero first-party tracking cookies, analytics SDKs, or ad networks.
  • The Support section embeds the official live GitHub Sponsors button (<iframe> from github.com/sponsors/DurchEins/button), which sends a browser request to GitHub when loaded.
  • Optional client-side GitHub API (api.github.com) queries retrieve the latest release metadata and star count; Google Fonts delivers page typography.
