November 21, 2026

1.45.1 (223)

Patch & Fix
  • New ApkUp Website & Web Wiki ApkUp now has a dedicated website at [durcheins.github.io/apkup](https://durcheins.github.io/apkup/) with feature overviews, downloads, and guides; the Help button in Settings links straight to the new Web Wiki.
  • Support & Rate ApkUp The [About](apkup://support) section now gathers [project support options](apkup://support) alongside quick star and review links for GitHub, GitLab, and supported app stores.
  • Expressive Interactions & Detail Polish Live install step indicators, a floating batch action dock, hold-to-peek app details with tap-to-copy signer fingerprints, and adaptive side-pane details on wider screens.
  • Seamless In-App Browsing External links, repository pages, guides, and browser fallbacks now open seamlessly right inside ApkUp without throwing you out into a separate browser window.
  • Security & Reliability Stronger pre-uninstall checks for Root rollbacks and split APKs, cleaner diagnostic log redaction, and protection against malformed filter patterns.
  • General Improvements Fixed pull-to-refresh overlap on the Updates tab, more accurate Shizuku status badges on resume, and minor wording and stability refinements across all nine languages.

Feature Update
Beta Channel & M3 Expressive
+ Updated Wiki
  • Material 3 Expressive Look & Off-White Unified Amber theme across dark mode and a softer off-white light mode, plus an optional Dynamic Color (Material You) toggle in appearance settings.

November 16, 2026

1.44.0 (203)

Feature Update
Source Priority, Pre-Releases & Rollback
+ Time Window & Checks
  • Source Priority & App Pinning Reorder update sources in settings by holding and dragging, and pin individual apps to a preferred source with automatic fallback.
  • Pre-Release Channels & Time Window Pick individual pre-release channels (Beta, RC, Alpha, or Nightly) globally or per app, and configure quiet hours or active windows for background updates.
  • Automatic Rollback Backups Optionally back up the currently installed app before updating for quick rollbacks from Update History (in-place with Root, guided two-step flow without Root) or APK export.
  • Compatibility Guard & Reliable APK Export Checks minimum Android version and CPU architecture before installing to prevent retry loops, while saving APKs locally now works even when the installed app uses a different signing key.
  • Watchlist Seen State, App Watcher & Source Health Track seen versions for watched apps, import lists from App Watcher, inspect source health and cooldowns in Setup, and see distinct F-Droid icons in a compact scan tray.
  • General Improvements Full settings backup coverage for all new options, atomic downloads, and overall speed, stability, and usability polish.

  • Instant Search & Flexible Sorting Both main tabs now let you search instantly and sort by name, source, release date, or last updated time.
