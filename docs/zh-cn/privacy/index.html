隐私政策

最后更新：2026 年 11 月 13 日 • 基于 ApkUp 仓库中的 PRIVACY.md。

✓ 100% 本地运行
  • 应用扫描、版本比对与 SHA-256 校验
  • 基于硬件密钥库的 Google Tink (AES-256-GCM) 加密令牌
✕ 绝不发送
  • 零遥测、零崩溃追踪器、零广告 ID
  • 无开发者后台服务器、无账号体系、无统计分析

1. 无开发者服务器、无统计、无广告

  • 没有任何记录用户查询或 IP 地址的 ApkUp 服务器、代理或数据库。
  • 无需注册、无用户账号、无崩溃追踪器（Firebase、Sentry、Crashlytics）或行为遥测。
  • 绝不收集 IMEI、硬件序列号、MAC 地址或广告 ID。

2. 明确的更新源同意与网络活动

  • 首次启动时 ApkUp 会显示「选择更新源」同意对话框 —— 在此之前不会发出任何外部请求。
  • F-Droid 与 IzzyOnDroid 索引在本地下载并比对，不会上传您的应用列表。
  • Google Play 检查使用匿名 Aurora Dispenser 令牌与最小化兼容配置 —— 无需个人 Google 账号。

3. 加密本地存储与开源审计

所有偏好设置、仓库绑定与可选 API 令牌均通过由 Android Keystore 保护的 Google Tink (AES-256-GCM) 静态加密。云备份与明文 HTTP 均已禁用。
