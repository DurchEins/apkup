Android 10 – 17 • 侧载指南

在 Android 上安装未知应用

30 秒开启 Android「安装未知应用」权限的方法 —— 或使用 Shizuku、ADB 或 Root 实现静默后台更新。

标准 Android • 30 秒

传统「安装未知应用」权限

  1. 01
    下载并打开最新的已签名 APK

    通过我们的 下载页面 或 GitHub Releases 下载最新已签名的 .apk(Up) 文件，并在浏览器或文件管理器中点击打开。

  2. 02
    开启「允许来自此来源的应用」

    当 Android 弹出提示时点击设置，为您的浏览器开启允许来自此来源的应用，然后点击安装。

  3. 03
    为 ApkUp 授予一次相同权限

    在 ApkUp 内首次更新应用时，为 ApkUp 也授予一次相同权限 —— 或使用 Shizuku/Root 实现完全静默的后台更新。

Shizuku • ADB • Root

通过 Shizuku 或 ADB 的进阶方式

通过 Shizuku（Android 11+ 无线调试）、电脑端 adb install -r ApkUp.apk 或 Root (su) 安装，将直接使用 Android 的开发者安装通道。
