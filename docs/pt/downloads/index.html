Checksum SHA-256 ao vivo

Um checksum SHA-256 é a impressão digital única de 64 caracteres do APK. Se um único byte for alterado, o hash não baterá.

Comandos de verificação local

Execute o comando do seu sistema na pasta Downloads para calcular o hash SHA-256 do arquivo e comparar com o oficial à esquerda.

Guia passo a passo na Wiki →
Linux / macOS sha256sum -c SHA256SUMS
Windows PowerShell Get-FileHash .\ApkUp-*.apk -Algorithm SHA256
